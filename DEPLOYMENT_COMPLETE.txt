Quick Start (30 seconds):
  1. cd FujiRecipesMac/macos
  2. swift build -c release
  3. .build/release/FujiRecipesMac

With Camera:
  1. sudo pkill ptpcamerad
  2. Connect X100VI in USB RAW mode via USB-C
  3. Launch app
  4. Camera tab → Click "Connect"
  5. Darkroom tab → Select RAF → "Start Conversion"
  6. Check camera LCD after 60-90 seconds

 ⚠️ KNOWN LIMITATIONS (Documented in App)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Preset Slot Writes (0xD18C)
   Issue:  macOS libusb returns 0x2019 (DeviceBusy)
   Impact: Can't write C1-C7 slots from app
   Fix:    Use app recipes instead
   Status: Documented in Limitations modal

2. RAF Conversion Results
   Issue:  X100VI doesn't return JPEG via PTP
   Impact: Result appears on camera LCD/SD card
   Fix:    User checks camera manually
   Status: Explained in Darkroom result note

3. Profile Read After Upload
   Issue:  0xD185 fails with LIBUSB_ERROR_IO (-2)
   Impact: Can't verify profile after conversion
   Fix:    App doesn't attempt read
   Status: Known libusb limitation

All limitations explained in-app via:
  • "Known Limitations" modal (Camera tab)
  • "Troubleshooting" modal (on error)
  • Result location note (Darkroom tab)

FujiRecipesMac (UI)
    ↓
CameraManager (orchestrator)
    ├─ readCStates()        → Read C1-C7 from camera
    ├─ writeLoadout()       → Write to C-slot (fails on macOS)
    ├─ importRecipe()       → Apply recipe to C-slot
    └─ convertRAF()         → Full conversion pipeline
    ↓
X100VIHelperClient (PTP client)
    ├─ connect()            → Opens USB session
    ├─ readProperty()       → Reads device property
    ├─ writeProperty()      → Writes device property
    └─ convertRAF()         → Full pipeline
    ↓
x100vi_helper (C executable)
    ├─ connect              → libusb OpenSession
    ├─ read_property        → GetProp PTP command
    ├─ write_property       → SetProp PTP command
    ├─ load_raf             → SendObjectInfo + SendObject2
    ├─ trigger_conversion   → SetProp 0xD183
    └─ wait_result          → Poll GetObjectHandles
    ↓
X100VI Camera (USB PTP)
