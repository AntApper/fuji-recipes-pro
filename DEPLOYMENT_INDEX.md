↓\nCameraManager.connect(X100VIHelperClient())\n    ├─ X100VIHelperClient finds x100vi_helper binary\n    ├─ Spawns process (stdin/stdout JSON-RPC)\n    ├─ Sends: {\"command\": \"ping\"}\n    ├─ Receives: {\"success\": true}\n    └─ Updates status → .connected\n    ↓\nCameraManager.readCStates() [7 parallel reads]\n    ├─ For slot 1-7:\n    │   ├─ Sends: {\"command\": \"read_preset_slot\", \"index\": 1}\n    │   └─ Receives: {\"name\": \"...\", \"properties\": {...}}\n    └─ Returns: [PTPClientPresetData × 7]\n    ↓\nLoadoutStore.syncFromCameraPresetData()\n    ├─ Updates C1-C7 loadouts\n    └─ Persists to UserDefaults\n    ↓\nUI updates with camera info + C1-C7 grid\n```\n\n### RAF Conversion\n```\nUser selects RAF file\n    ↓\nUser clicks \"Start Conversion\"\n    ↓\nconvertRAF() in RAFDarkroomView\n    ├─ Loads RAF from disk\n    ├─ Creates RAFFile object\n    └─ Calls manager.convertRAF(raf)\n    ↓\nCameraManager.convertRAF()\n    └─ Calls client.convertRAF(raf)\n    ↓\nX100VIHelperClient.convertRAF()\n    ├─ Sends: {\"command\": \"load_raf\", \"path\": \"/path/to/photo.RAF\"}\n    ├─ Helper uploads via vendor commands\n    ├─ Sends: {\"command\": \"trigger_conversion\", \"value\": 0}\n    ├─ Polls: {\"command\": \"wait_result\"}\n    └─ Returns JPEGFile (or nil)\n    ↓\nRAFDarkroomView updates progress\n    ├─ progress = 0.7 (upload)\n    ├─ progress = 1.0 (complete)\n    └─ status = \"✓ Check camera LCD/SD card\"\n```\n\n---\n\n## 🎯 Feature Checklist\n\n### Recipes Tab\n- ✅ Load recipe database from JSON\n- ✅ Display
